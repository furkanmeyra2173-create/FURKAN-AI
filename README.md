# FURKAN AI

A multilingual Android personal AI assistant.

## Current milestone
- Native Android app using Kotlin and Jetpack Compose
- Initial dark assistant home screen
- GitHub Actions workflow for building a debug APK

## Build
Open the **Actions** tab and run **Build FURKAN AI APK**, or push a commit to `main`.

When the workflow succeeds, download the `FURKAN-AI-debug` artifact.

## Planned milestones
1. Chat interface and secure AI backend connection
2. Speech-to-text and selectable text-to-speech voices
3. Conversation memory with user controls
4. Web search and source citations
5. User-approved Android actions and app launching
6. Camera and document analysis

## Security
Never commit API keys, passwords, or private tokens. AI provider keys must be stored on a secure backend, not inside the APK.
